## 📖 About This Repository

This repository holds the complete teaching material for **PSM-104: Power System Planning and Reliability**, an M.Tech (EE) course covering generation, transmission and distribution planning together with probabilistic reliability assessment. It is maintained for the benefit of students enrolled in the course and anyone else studying the subject.

All numerical software content in this repository uses **open-source tools only** (Python, GNU Octave, Scilab). No proprietary software is required to complete any assignment or reproduce any example.

## 🗂️ Repository Structure

```text
.
├── 01_CourseFile          # Syllabus, lesson plan, CO-PO mapping, academic calendar alignment
├── 02_LectureNote         # Module-wise class notes (Modules 1-5)
├── 03_EndSemQuestionSet   # End-semester examination question papers
├── 04_QuestionBank        # Consolidated question bank for revision and practice
├── 05_Assignment          # Home assignments (Option A: classical numerical | Option B: open-source coding)
└── 06_ClassTest           # Class Test question papers and sample answer keys
```

| Folder | Contents |
|---|---|
| `01_CourseFile/` | Master lesson plan, learning objectives, assessment framework, and the institutional academic calendar mapping for the running session |
| `02_LectureNote/` | Full class notes for Module 1 (System Planning Fundamentals) through Module 5 (Distribution Planning), each with worked examples |
| `03_EndSemQuestionSet/` | Past and current end-semester theory question papers |
| `04_QuestionBank/` | Topic-organized practice questions spanning all five modules |
| `05_Assignment/` | Home assignments; each offers a classical numerical track and an open-source coding track (student's choice) |
| `06_ClassTest/` | Class Test (CIA) question papers, with sample answer keys where provided |

## 📝 Assessment Framework

Internal assessment follows the institution's CIA structure:

- **CIA01**: Class Test 1 (Modules 1 & 2) + Assignment 1 + Attendance
- **PCIA**: Institutional interim checkpoint (Module 3)
- **CIA02**: Class Test 2 (Modules 3 to 5) + Assignment 2 + Attendance

The better of CIA01 and CIA02 is carried forward for final internal marks, as per institutional policy. Exact dates for the current session are listed in `01_CourseFile/`.

## 🛠️ Tools and Software

This course is taught entirely with open-source tools:

- **Python**: NumPy, SciPy, Pandas, Matplotlib
- **GNU Octave**: Free, open-source platform for numerical computing
- **Scilab**: Numerical computation and dynamic system modeling (Xcos)
- **R**: Statistical analysis for reliability data
- **LaTeX** (lualatex): All notes and question papers are typeset in LaTeX

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/KingsukMajumdar/PowerSystemAndReliabilityNoteForStudents.git
cd PowerSystemAndReliabilityNoteForStudents
```

To compile any of the LaTeX class notes locally:

```bash
lualatex filename.tex
```

Required LaTeX packages include `tcolorbox`, `amsmath`, `fontawesome5` (free icon set), `tikz`, and `circuitikz`. Most TeX distributions (TeX Live, MiKTeX) include these by default.
